# 🏆 Football Fans

Добро пожаловать в Football Fans — ваш универсальный ресурс для всего, что связано с футболом! Этот проект предоставляет актуальную информацию о матчах, командах, игроках и турнирах, а также удобные инструменты для анализа и отслеживания статистики.

## 🚀 Основные возможности

- 📅 Расписание матчей: Всегда будьте в курсе предстоящих игр.

- 🏅 Турнирные таблицы: Актуальные данные о лигах и кубках.

- ⭐ Избранное: Сохраняйте любимые команды и игроков для быстрого доступа.
  </br>

## 🛠️ Установка и запуск

- Убедитесь, что у вас установлены Node.js и npm.

- Клонируйте репозиторий: git clone git@github.com:AlbertRevazov/Football-Fans.git

- Перейдите в директорию проекта: <code>cd client</code> и <code>cd server</code>

- Установите зависимости: <code>npm install</code>

- Создать и заполнить файл .env в директории server.

- Запустите проект: <code>npm run dev</code>
  </br>

## 📂 Структура проекта

Это модифицированная Feature-Based Structure с добавлением слоёв для глобальных ресурсов. Такой подход часто называют "Гибридной структурой", так как он сочетает:

Преимущества Feature-Based:
Удобство разработки и изоляция функциональных блоков.

Преимущества Layer-Based:
Централизованное управление общими ресурсами и состоянием.
